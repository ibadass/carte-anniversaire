# 🎂 Carte d'anniversaire

Appli web mobile (installable en PWA) : feux d'artifice, bisous, livres, BD belges et françaises, vœux.

## Personnaliser
- Édite `config.js` (nom, âge, message, livres, BD, vœux, ordre des modules).
- Ou via l'URL : `?nom=Jeanne&age=80&de=Tes+enfants&modules=feux,bd,voeux`
